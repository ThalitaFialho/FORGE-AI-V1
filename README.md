# FORGE AI V1

FORGE AI is a project development platform created to help turn an idea
into a structured project.

The first version focuses on the interface and the basic structure of
the platform, including project creation, idea analysis, roadmaps,
checklists and progress.

## Features

-   Dashboard
-   New project
-   Idea description
-   Project categories
-   Idea analysis
-   Development roadmap
-   Development checklist
-   Project progress
-   Saved projects

## Technologies

-   HTML5
-   CSS3
-   JavaScript

## Development

FORGE AI V1 is also part of my process of learning web development.

I am building the project while learning HTML, CSS and JavaScript,
applying each new concept directly to the product.

The project will continue to evolve as I learn more about frontend
development, backend development, databases, APIs and AI.
